        Configuración guiada

        Prepara Kuali para tus reuniones

        Descarga un modelo local y conecta una integración o ambas. Puedes volver aquí en cualquier momento.

        Opción 1

        Discord

        Sin configurar
        Paso 1 de 3 Crea la aplicación
        1
        Portal de desarrolladores

        Crea una aplicación para Kuali

        Abre el portal, inicia sesión y pulsa Nueva aplicación. Escribe Kuali, acepta las condiciones y confirma con Crear.

        Discord creará un bot independiente para Kuali; tu cuenta personal nunca se automatiza.

        Si el portal aparece en inglés: New Application y Create.

        Ver ejemplo

        Ejemplo: botón “Nueva aplicación”.

        2
        Token privado

        Copia el token y escribe tu usuario

        En el panel izquierdo entra en Bot. Pulsa Restablecer token, confirma y copia el valor que muestra Discord.

        El token es una contraseña. No lo publiques, no lo subas a Git y no lo envíes a nadie.

        Ver ejemplo

        Ejemplo: Bot → “Restablecer token”.

        Usa el @usuario, no el nombre visible del perfil.

        Abre tu perfil desde la esquina inferior izquierda de Discord y pulsa el icono de copiar junto a tu usuario.

        Ver ejemplo

        Ejemplo: abre tu perfil y pulsa el icono junto a tu usuario.

        Kuali comprobará el token y abrirá automáticamente la autorización con los permisos correctos.

        3
        Autorizar servidor

        Añade Kuali a tu servidor

        En la ventana de Discord elige Añadir a un servidor, selecciona dónde usarás Kuali y pulsa Autorizar. Los ámbitos y permisos ya están preparados.

        • Ver canales
        • Enviar mensajes
        • Enviar mensajes en los hilos
        • Insertar enlaces
        • Adjuntar archivos
        • Conectar
        • Hablar
        • Usar actividad de voz

        Kuali no solicita Administrador ni acceso para leer tu historial de mensajes.

        Después podrás cambiar el token o el usuario en Ajustes → Discord.

        • /grabar · /recordInvita a Kuali al canal de voz en el que estás, aunque el seguimiento esté apagado.
        Opción 2

        Meet, Teams y Zoom

        Chrome Web Store

        Google Meet tiene soporte estable. Microsoft Teams y Zoom tienen soporte experimental y parcial.

        Paso 1 de 3 Instala la extensión
        1
        Navegador

        Instala Kuali desde Chrome Web Store

        Elige el navegador donde usarás Meet, Teams o Zoom. Kuali abrirá su ficha oficial para que solo tengas que pulsar Instalar.

        Chrome Web Store también permite instalar extensiones en Edge, Brave y Arc.

        Instalación manual

        Úsala solamente si la tienda no está disponible. Abre el administrador del navegador, activa Modo desarrollador y pulsa Cargar descomprimida.

        En el selector de carpetas presiona ⌘ Shift G, pega esta ruta y confirma.

        Buscando carpeta…
        2
        Barra del navegador

        Fija Kuali para tenerlo a mano

        Abre el menú de extensiones del navegador y fija Kuali. Así podrás iniciar o detener una grabación desde cualquier reunión.

        ✓
        Prueba rápida

        Comprueba que Kuali está disponible

        Mantén abierta la aplicación, entra a una reunión y pulsa el icono de Kuali. La extensión debe indicar que la app está conectada y permitirte grabar.

        El puerto predeterminado es 9099. Solo necesitas tocarlo si lo cambiaste en Ajustes → Integraciones.
