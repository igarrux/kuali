# Kuali support

## Setup and usage questions

Read the [visual setup guide](https://kuali.garrux.dev/guides/) first. If the
answer is not there, open a
[GitHub Discussion](https://github.com/igarrux/kuali/discussions/categories/q-a)
so the answer can help other users.

## Bugs

Use the matching [issue template](https://github.com/igarrux/kuali/issues/new/choose).
Include the Kuali version, operating system, meeting platform, Whisper model,
transcription language, and minimal reproduction steps.

Never attach unredacted meeting content, participant names, bot tokens, API
keys, webhook secrets, or private endpoints.

## Feature ideas

Open a [feature discussion](https://github.com/igarrux/kuali/discussions/categories/ideas)
before proposing a large architectural change. Focused improvements can use the
feature-request issue template directly.

## Security and sensitive reports

Follow [SECURITY.md](SECURITY.md) and use
[private vulnerability reporting](https://github.com/igarrux/kuali/security/advisories/new).
Do not disclose an exploitable vulnerability or private meeting data publicly.
