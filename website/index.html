Native by design

Lightweight while waiting.
Powerful when it matters.

Kuali is a native Rust app. Its Discord bot runs from your Mac, and browser meetings reach Kuali over 127.0.0.1. There is no Kuali server in the middle. Whisper enters memory only when the first active meeting needs it and is released after the last one ends.

    Native desktop core

  • ~40 MB

Measurements are approximate observations on Apple Silicon; actual memory use varies by meeting and system. Downloaded weights remain on disk, but the loaded model releases RAM after the final active meeting ends. Concurrent meetings share one loaded model.

Why Kuali is different

Built around each person.
Not one mixed recording.

Kuali preserves participant identity before Whisper sees the audio, guides anyone through setup, and returns useful results to the tools already in your workflow.

NO DIARIZATION 01

Voices are separated at the source

Discord and Google Meet provide participant context alongside live audio. Kuali keeps platform IDs, names, avatars, and words connected before transcription instead of guessing speakers afterward from one mixed recording.

3 STEPS 02

Setup that teaches itself

Interactive, bilingual guides connect Discord or Google Meet in three steps, with real screenshots and configuration saved as you go.

CLI OR API 03

Use the AI you already configured

Reuse an authenticated Claude Code, Codex, or Gemini CLI session for summaries. Prefer an API? Kuali also supports Anthropic, OpenAI, Gemini, and OpenAI-compatible providers such as Ollama or LM Studio.

AUTOMATIC 04

It can follow you on Discord

Join a configured voice channel and Kuali can enter after you automatically. Pause following at any time or invite it manually.

INSIDE DISCORD 05

Kuali updates one polished Discord card with tasks and private buttons for the summary, key points, decisions, open questions, and paginated full transcript. Complete text files remain available to download.

Questions, answered

Before you invite Kuali.

Does Kuali upload meeting audio?

No. Whisper and Silero process raw audio in memory on your computer. Kuali does not retain an audio recording or send it to a Kuali-operated service.

Can it tell speakers apart?

Yes. Kuali preserves participant identity when Discord or the browser meeting service exposes it. If a source provides mixed audio, Kuali labels it honestly instead of inventing attribution.

Do I need an external AI provider?

No. Transcription works locally without an LLM. Summaries and tasks are optional and remain off whenever you disable them in Settings.

How much memory does Kuali use?

In testing on Apple Silicon, Kuali used about 40 MB while waiting and up to about 600 MB while transcribing with the recommended Q5 model. Actual use varies. Whisper is loaded for the first active meeting, shared by concurrent meetings, and released after the final one ends.

Does Kuali announce that it is transcribing?

On Discord, Kuali plays and posts the consent notice when it joins and repeats it for people who arrive later. It also keeps an append-only consent audit log.

Is Kuali free?

Yes. The desktop application is open source under MIT. The interoperable browser extension is distributed under Apache-2.0.
