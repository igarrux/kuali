Complete setup guide

From download to your first live transcript.

Choose Discord, browser meetings, or both. The desktop app repeats this guide and can save the configuration as you go.

01 · Desktop

Install Kuali on macOS

The current release supports macOS 11 or newer on Apple Silicon. Homebrew verifies the checksum pinned by Kuali’s tap before installing the application.

Terminal · macOS
$ brew install --cask igarrux/kuali/kuali
$ xattr -dr com.apple.quarantine /Applications/Kuali.app

Open Kuali from Applications. On first launch, the app opens its guided setup automatically. You can return to it later from the Guide button.

02 · Transcription

Download a Whisper model

Model weights are separate from the application. Open Settings → Transcription models and choose one. Kuali verifies the download before using it.

Start with Large v3 Turbo Q5

It is the recommended balance for most Apple Silicon Macs: multilingual, accurate, and much lighter than the full model.

Use Large v3 Turbo for maximum quality

Choose the full model when your Mac has enough memory and accuracy matters more than download size.

Add product names to terminology

In Settings → Transcription → Special terminology, add names such as internal products, acronyms, or people that Whisper should preserve.

03 · Discord

Connect Kuali to Discord

You will create a dedicated Discord bot. Kuali never automates your personal account, and the token should be treated like a password.

Open the Discord Developer Portal

Visit the Discord Developer Portal and sign in with your Discord account.

Select “New Application”

The button is in the upper-right corner. Name the application Kuali, accept Discord’s terms, and select Create.

Reset and copy the bot token

Open Bot in the left sidebar, select Reset Token, confirm, and copy the value Discord shows.

Never publish the token, commit it to Git, or send it to another person. Paste it only inside Kuali.

Enable Guild Install

Open Installation. Under Installation Contexts → Select Installation Methods, enable Guild Install.

Configure the install link and scopes

Choose Discord Provided Link. Under Default Install Settings → Guild Install → Scopes, add applications.commands and bot.

Select only the minimum permissions

Enable View Channels, Send Messages, Send Messages in Threads, Connect, Speak, and Use Voice Activity. Do not enable Administrator.

Invite the bot and connect your username

Copy the installation link, open it, and add Kuali to your server. Back in Kuali, paste the bot token and enter your exact Discord @username, not the display name.

Join a voice channel

With automatic Discord following enabled, Kuali joins after you. You can pause following from Home or invite it manually with /record or /grabar.

04 · Meet, Teams, and Zoom

Install the browser extension

The extension talks only to Kuali’s listener on your computer. Keep the desktop app open while recording a browser meeting.

Install from Chrome Web Store ↗

Choose your browser

The Chrome Web Store listing works in Chrome, Edge, Brave, and Arc. Select Add when your browser asks for confirmation.

Pin Kuali

Open your browser’s extensions menu and pin the Kuali icon for quick access from meetings.

Confirm the local connection

Join a meeting and open Kuali’s extension. It should report that the desktop app is available and let you start recording. The default local port is 9099.

For development or when the store is unavailable, the desktop guide still provides the manual unpacked-install option.

05 · Verification

Check your first call

Start with two participants if possible. Speak one at a time, then overlap briefly to confirm that activity and attribution react as expected.

  • Kuali shows the meeting under Live meetings.
  • The active participant lights up while speaking.
  • Text appears during the call, not only after it ends.
  • Muting a participant stops that participant’s activity.
  • Leaving the meeting finalizes it and releases the Whisper model.

Discord commands

  • /record · /grabarInvite Kuali to your current voice channel.
