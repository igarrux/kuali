# Security policy

## Supported versions

Security fixes are applied to the latest release and the current `main`
revision.

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/igarrux/kuali/security/advisories/new)
for vulnerabilities involving the loopback capture bridge, Discord bot,
credentials, meeting isolation, webhook signatures, or local data access.

Do not open a public issue containing meeting content, participant information,
bot tokens, API keys, webhook secrets, private endpoints, or proof-of-concept
code that exposes users before a fix is available.

Include the affected revision, operating system, reproduction steps, impact,
and any suggested mitigation. You should receive an acknowledgement within
seven days. No monetary bug-bounty program is currently offered.
